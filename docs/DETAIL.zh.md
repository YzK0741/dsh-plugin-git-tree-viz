# Git 历史

在 Harness 内浏览本地工作区的 Git 历史，查看分支图谱和文件差异、搜索与筛选提交类型、按变更规模排序、导出历史版本，并在明确启用源仓库读写后创建本地标签。

从侧栏打开 **Git 历史**，选择工作区或输入仓库路径，再选中提交。语言和主题跟随 Harness。**撤回软件标签** 仅删除本插件创建且未被修改的标签，保留手动标签及后来被改动的标签。标签须手动推送到远端。

需要兼容 Harness 0.2.2-alpha.2 的原生 Client/Connection 接口、Node.js 24.9+ 和系统 Git。导出不会下载子模块或 Git LFS 大文件。
